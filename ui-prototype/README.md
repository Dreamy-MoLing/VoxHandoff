# UI Prototype

这是 Agent_Talk 的独立 Web UI 效果范本，仅用于视觉与交互评审，不承载真实的 Agent、语音、网络或数据功能。

> 状态：已冻结为移动端视觉基线。后续正式实现应复刻这里的视觉语言与交互意图，再接入真实业务状态；本目录不作为生产代码依赖。

## 启动

```bash
npm install
npm run dev
```

然后打开 `http://127.0.0.1:5173/`。

## 当前交互

- 默认显示中央动态球体。
- 短按球体切换文字态；文字态显示对话内容，球体放大并由底边裁切。
- 长按进入语音录入视觉态：球体保持不变，球心显示波形；松开后模拟 TTS 输出状态。
- 文字态顶部显示连接状态与设置入口。连接状态默认只显示带光晕的光点；状态变化时显示胶囊文字，绿色状态 3 秒后隐藏，黄色与红色状态持续显示。
- 设置页提供亮暗主题、文字大小和自定义背景导入的视觉示例。

## 冻结基线

- 待机态：动态球体位于屏幕中央。
- 文字态：对话内容占主要阅读区域，球体放大并由底边裁切；顶部只保留连接状态光点和设置图标。
- 录音态：长按进入录音视觉状态，球体保持不变，仅在球心显示波形；松开后模拟 TTS 输出。
- 连接态：绿色已连接只显示带光晕的光点；黄色连接中、红色未连接显示常驻胶囊文字；状态切换时胶囊展示对应状态。
- 视觉基调：星空背景、深浅主题、平滑过渡、低文字密度和图形优先。

## 后续实现指针

- 页面结构与交互入口：`index.html`。
- 视觉 Token、布局、主题、球体和动效：`styles.css`。
- 原型交互状态：`app.js` 中的 `setTtsVisible`、`setVoiceRecording`、`setConnectionStatus`。
- 中央核心对应正式项目的 SignalCore；生产实现应以真实录音电平、TTS 播放包络和 Agent 事件驱动动效，不照搬原型里的本地计时器。
- 真实产品行为以 `../spec/PRODUCT.md` 为准，技术与状态边界以 `../spec/ARCHITECTURE.md` 为准，交付门槛以 `../spec/DELIVERY.md` 为准。
- 本原型的网页尺寸、示例文字、演示状态和 `setTimeout` 仅用于视觉评审，不是生产协议或业务状态定义。

## 文件

- `index.html`：原型页面结构。
- `styles.css`：主题、星空背景、球体动效和响应式布局。
- `app.js`：仅用于演示页面切换、点击、长按和状态变化。
- `package.json`：Vite 本地开发配置。

后续正式项目接入时，可将本目录作为视觉参考，重新实现真实的 Agent、STT、TTS、连接管理和设置持久化能力。
